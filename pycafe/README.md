# PyCafeサンプルと検証記録

ソースはこのディレクトリ内で管理します。記事の `literalinclude` と `{pycafe}` が同じファイルを参照するため、掲載コードと実行コードが一致します。

PyCafe公式Snippet方式で埋め込みを生成します。PyCafeアカウントや公開プロジェクトの作成は不要です。コードを更新してSphinxをビルドすると、生成されるURLも更新されます。公開プロジェクトへの手動アップロード方法はルートのREADMEを参照してください。
