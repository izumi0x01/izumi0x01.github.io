# NumPy配列の基本

## 配列とベクトル演算

NumPyの配列は複数の数値をまとめて扱います。演算は要素ごとに適用され、内積はベクトル間の関係を表します。

$$
\mathbf{a}\cdot\mathbf{b}=\sum_i a_i b_i
$$
