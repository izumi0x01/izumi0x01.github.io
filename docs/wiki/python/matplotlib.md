# Matplotlib Animation

Pythonの1つのソースからコード・実行結果・編集用セルを生成します。
GIFはページを開くと再生されます。Python環境の起動を待つ必要はありません。

## Sample Code

```{python-example}
:source: matplotlib/sine_animation.py
:mode: code
```

## Output

```{python-example}
:source: matplotlib/sine_animation.py
:mode: output
```

画像が表示されない場合はブラウザの開発者ツールのNetworkでGIFのURLとHTTPステータスを確認してください。

## Interactive Python

下のボタンでPython環境を起動し、コードを編集してRunで実行してください。
出力のPlayでアニメーションを再生できます。標準出力と例外もセルの下に表示されます。
ブラウザでは同じFuncAnimationをHTMLプレイヤーに変換します。
エディタは高さ720pxの枠内で表示され、長い出力はスクロールします。

```{python-example}
:source: matplotlib/sine_animation.py
:mode: interactive
```
