# Introduction

数式を読み、埋め込みのPythonコードを編集し、Shift+Enterで実行すると計算結果やグラフが表示されます。

初回はPyodideと必要なパッケージの取得に時間がかかります。Pythonはブラウザ内で動作し、外部のPythonサーバーは不要です。

各埋め込みセルには独立したPythonカーネルがあります。同じセル内では実行した変数を引き続き使用できます。ページを開いただけではコードは実行されません。

標準出力と例外はコンソールに表示され、Matplotlibのグラフはインラインで表示されます。

記事はMyST Markdownで執筆し、数式は `$...$` または `$$...$$` で記載できます。
