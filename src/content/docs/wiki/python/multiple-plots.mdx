## Figureを分けて比較する

figureを呼ぶと新しい描画領域を作れます。複数のFigureは同じセルの出力欄に順番に表示されます。

$$
\cos^2 x + \sin^2 x = 1
$$

## 実行して確かめる

コードを編集して **Run** を押してください。初回は実行環境のダウンロードに時間がかかります。

<PythonRunner code={"import numpy as np\nimport matplotlib.pyplot as plt\nx = np.linspace(0, 2*np.pi, 100)\nfor fn in [np.sin, np.cos]:\n    plt.figure(figsize=(5, 2))\n    plt.plot(x, fn(x))\n    plt.title(fn.__name__)\nplt.show()"} />

## 試してみよう

数値やパラメータを変更し、式が予測する結果と出力を比較してください。セルの変数は実行ごとに初期化されます。
